# 产品定义

## 1. 产品名称

护康（HuKang）

## 2. 产品定位

面向普通用户的食品健康信息管理工具。核心目标是帮助用户记录已购食品/药品、理解食品标签信息，并管理保质期、新鲜度、营养与配料信息。

## 3. 当前目标用户

- 关注食品健康与营养的普通消费者
- 希望管理家中食品保质期的人
- 希望快速看懂配料表、营养成分表的人

## 4. 当前阶段

先完成 Android MVP 的产品定义与信息架构，不急于实现全部功能。

## 5. MVP 核心价值

用户拍摄或扫描食品信息后，能够：

1. 知道“这是什么商品”
2. 记录“什么时候买/什么时候过期”
3. 看懂“营养成分和配料”
4. 在需要时收到临期或过期提醒
5. 保留历史记录，方便回看

## 6. 暂不优先

- 社交功能
- 复杂账号体系
- 大规模推荐系统
- 过度复杂的健康诊断
- 为了视觉效果牺牲识别稳定性
