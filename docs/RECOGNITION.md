# 识别系统分类

识别系统拆成四条独立链路，不混为一个“拍照识别”。

## 1. 条码识别

目标：
- 识别 EAN / UPC 等商品条码
- 查询商品基础信息

输出：
- 商品名
- 品牌
- 规格
- 厂商 / 产地
- 可用的食品数据库信息

## 2. 营养成分表 OCR

目标：
- 识别能量、蛋白质、脂肪、碳水、钠等
- 尽量保留单位和每 100g / 每份语义
- 添加糖如有可靠来源，应单独展示

关键问题：
- 表格结构
- 小字体
- 反光
- 包装弯曲
- OCR 数字与单位误识别

## 3. 配料表 OCR

目标：
- 提取完整配料文本
- 保留原始文本
- 再做结构化分析

后处理：
- 添加剂
- 过敏原
- 高关注成分

## 4. 生产日期 / 批次

目标：
- 识别生产日期
- 识别保质期
- 必要时由用户确认

## 联网增强原则

联网不能只是“按钮存在”，需要明确：

本地识别 → 置信度判断 → 联网补全 / 搜索 → 结果融合 → 用户确认

## 失败策略

任何识别失败都应提供：
- 失败原因
- 重拍建议
- 手动输入入口
- 是否尝试联网
