# UI / UX 分类

## 主导航

底部 Dock 暂定：

1. 健康
2. 管理
3. 我的

## 健康页

- 今日营养概览
- 营养差值
- 快速识别入口
- 最近识别记录

## 管理页

- 食品 / 药品列表
- 新鲜度与临期状态
- 历史记录
- 新增记录入口

## 拍照识别

拍照前先选类别：

- 扫商品码
- 拍营养成分表
- 拍配料表
- 拍生产日期

每类入口应提供简单示意图与拍摄提示。

## 交互原则

- 返回手势不能直接退出 App
- 日期信息允许展开查看
- 识别失败必须告诉用户“为什么失败、下一步怎么办”
- 联网增强是否触发，需要给用户明确状态
- 视觉可采用轻量玻璃质感，但可读性优先

## 吉祥物

吉祥物可用于：
- 启动页
- 空状态
- 识别引导
- 成功 / 失败提示

不要让吉祥物干扰核心信息阅读。
