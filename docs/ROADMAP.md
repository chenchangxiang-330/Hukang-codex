# 开发路线

## Phase 0 — 现在：项目整理

目标：
- 明确产品边界
- 建立目录与文档体系
- 固化 MVP
- 明确识别链路
- 暂不写业务代码

## Phase 1 — 技术方案

需要确定：
- Android 技术栈
- 本地数据存储
- OCR 方案
- 条码扫描方案
- 联网商品数据库
- 图片处理流程

## Phase 2 — MVP

先跑通最短闭环：

拍摄 / 扫码 → 识别 → 用户确认 → 保存 → 列表查看 → 临期提醒

## Phase 3 — 识别质量

重点解决：
- OCR 准确率
- 包装反光 / 弯曲
- 表格结构
- 联网补全
- 错误提示

## Phase 4 — UI 与数据可视化

- 营养图
- 添加糖独立展示
- 玻璃质感
- 吉祥物整合
- 历史记录体验

## Phase 5 — 扩展

再评估：
- iOS
- macOS
- Windows
- 登录与云同步
