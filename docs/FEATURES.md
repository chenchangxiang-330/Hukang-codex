# 功能分类

## A. 健康

- 今日营养概览
- 营养摄入与目标差值
- 添加糖单独展示
- 食品营养信息详情
- 配料表分析
- 过敏原 / 添加剂提示

## B. 管理

- 已购食品 / 药品清单
- 生产日期、保质期与新鲜度
- 临期提醒
- 已过期提示
- 拍照存证
- 历史记录

## C. 识别入口

识别入口必须明确区分：

1. 商品条码
2. 营养成分表
3. 配料表
4. 生产日期 / 批次

避免用“一个万能拍照按钮”承担所有识别任务。

## D. 我的

待进一步定义。当前只保留：
- 基础个人资料
- 设置
- 提醒设置
- 数据管理
- 关于护康

## MVP 优先级

### P0
- 商品记录
- 条码识别
- 营养成分表识别
- 配料表识别
- 日期记录
- 保质期提醒
- 历史记录

### P1
- 联网商品信息补全
- 添加剂 / 过敏原解析
- 营养可视化
- 拍照引导与示例

### P2
- 更复杂的个性化建议
- 多平台同步
- 账号体系
