# Hukang-codex

护康（HuKang）的 Codex 独立开发仓库。

## 当前阶段

本仓库目前只做**项目分类、需求整理、设计约束和交接文档**，暂不编写业务代码。

## 目录

- `docs/`：产品、功能、交互、识别、数据与路线规划
- `design/`：UI/UX、视觉规范、吉祥物与设计资产说明
- `assets/`：图片、图标、示例素材的分类规则
- `research/`：竞品、API、数据库与技术调研
- `tests/`：后续测试策略、测试样本与验收标准
- `handoff/`：给 Codex / 其他模型或开发者的交接说明

## 原则

1. 先明确问题和边界，再写代码。
2. 文档先成为“单一事实来源”，避免不同模型各自理解。
3. OCR、条码、联网查询与数据结构分开设计。
4. MVP 优先保证可用、可验证、可迭代。
5. 重要改动必须同步到 `handoff/HANDOFF.md`。
